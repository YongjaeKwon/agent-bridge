# Session End Hook

세션 종료 시 자동 실행. 데일리 회의록 생성 및 정리.

## 자동 실행 작업

1. **세션 활동 수집**
   - 이번 세션에서 변경한 파일 목록
   - 생성/업데이트한 Linear 티켓 목록
   - 호출한 에이전트 목록

2. **Notion 데일리 회의록 생성**
   - "📝 회의록" DB에 새 페이지 추가
   - 회의 유형: "데일리 스탠드업"
   - 참여 에이전트: 이번 세션에 호출된 에이전트들
   - 날짜: 오늘
   - 내용 구조:
 ## 오늘 한 일
 - [완료 티켓 목록]
 
 ## 진행 중
 - [진행중 티켓 목록]
 
 ## 다음 작업
 - [백로그 우선순위 높은 티켓]
 
 ## 변경된 파일
 - [파일 목록]
 
 ## 이슈 / 블로커
 - [발견된 문제들]
3. **Linear 사이클 상태 확인**
   - 현재 사이클 진행률 계산
   - 완료/전체 비율 보고

 ## 활동 로그
 - "📋 데일리 회의록 생성 완료: [Notion URL]"
