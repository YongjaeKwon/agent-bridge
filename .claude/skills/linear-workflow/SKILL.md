\## When to Use

\- 새 작업 시작할 때

\- 작업 완료했을 때

\- 버그 발견했을 때

\- 에이전트에 작업 배정할 때



\## Ticket 상태 흐름

백로그 → 진행중 → 리뷰중 → 완료



\## Rules

\- 모든 작업은 Linear 티켓 기반으로 진행

\- 작업 시작 시 반드시 상태 "진행중"으로 변경

\- 완료 시 Notion 회의록 자동 생성

\- 버그 발견 시 즉시 티켓 생성 후 보안 에이전트 호출



\## 티켓 명명 규칙

\- feat: \[플랫폼] 기능명

\- fix: \[플랫폼] 버그내용

\- content: \[주제] 블로그글제목

\- test: \[플랫폼] 테스트내용
